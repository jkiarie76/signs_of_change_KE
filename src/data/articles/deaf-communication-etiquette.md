# Respectful Communication with Deaf People

Good communication begins with respect, patience, and a willingness to learn.

## Start with respect

Deaf people have different communication preferences. Ask rather than assume.

## Communication matters

Learning basic Kenyan Sign Language can make everyday interactions more inclusive.

## Building better connections

Small changes in how we communicate can create more welcoming spaces for everyone.
